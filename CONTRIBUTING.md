# Contributing

Thanks for your interest in Traveler Quartet.

- **License.** By contributing (code, art, text or anything else), you agree that your contribution is licensed under
  this project's licenses: the code under PolyForm Noncommercial 1.0.0 (`LICENSE`), art and texts under
  CC BY-NC-SA 4.0 (`LICENSE-CONTENT.txt`).
- **Tests.** Run `python -m pip install -e ".[dev]"`, then `python -m pytest`. A change to the rules comes with a test.
- **Python 3.10.** Don't use syntax newer than Python 3.10.
- **No keys.** Never commit an API key or a `.env` file.

The project is in its design phase and moves slowly, so issues are the best place to start a conversation.
